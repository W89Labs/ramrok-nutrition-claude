# RAMROK Nutrition Database

The seven skills cover food search, barcode lookup, nutrition facts, portions, comparisons, recipes and reviewed corrections. Sign in through the RAMROK authorization window, choose a project and approve the permissions shown. Keep verification codes and credentials in that window. Use get_catalog_capabilities to see the current edition, allowed tools and usage. Free accounts have 25 monthly read units shared across REST and MCP. Keep result-level source notices, units and edition with the values. [Developer documentation](https://nutrition.ramrok.com/docs)

Projects can propose corrections when their connection exposes the proposal tool and has explicit foods:submit permission. The standard directory connection requests read and recipe scopes. A reviewer evaluates each proposal. [Source licenses](https://nutrition.ramrok.com/licensing) · [Privacy](https://nutrition.ramrok.com/privacy) · [Support](https://nutrition.ramrok.com/support)

# RAMROK Nutrition Database

The seven skills cover food search, barcode lookup, nutrition facts, portions, comparisons, recipes and reviewed corrections. Sign in through the RAMROK authorization window, choose a project and approve the permissions shown. Keep verification codes and credentials in that window. Use get_catalog_capabilities to see the current edition, allowed tools and usage. Free accounts have 25 monthly read units shared across REST and MCP. Keep result-level source notices, units and edition with the values.

To scale a match, pass the exact foodId from Search Foods or Barcode Lookup to Calculate Portions. Use a source-supplied serving for a kitchen measure, or weigh it in grams. Recipe Nutrition identifies each ingredient before combining amounts. [Combine tools](https://nutrition.ramrok.com/docs#combine-tools)

[Developer documentation](https://nutrition.ramrok.com/docs)

Projects can propose corrections when their connection exposes the proposal tool and has explicit foods:submit permission. The standard directory connection requests read and recipe scopes. A reviewer evaluates each proposal.
